# 判例レンズ

裁判所ウェブサイト「裁判例検索」に掲載されている裁判例 65,468件（2025年1月時点）を、ブラウザだけで横断検索できる判例検索アプリです。

- 公開ページ: https://hibix-claude.github.io/hanrei-lens/
- 原データ: 裁判所ウェブサイト（courts.go.jp）。収集済みデータ [japanese-law-analysis/data_set](https://github.com/japanese-law-analysis/data_set)（CC0）を利用
- 判示事項・裁判要旨は裁判所の記載、主文冒頭はPDFからの機械抽出、70件の「解説」は編集部の要約です。正確な内容は全文PDFで確認してください。
- 本サイトは法的助言を提供するものではありません。

`index.html` がアプリ本体、`data/` が圧縮済みの裁判例データ（base64）です。
