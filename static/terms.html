1. 本サイトについて

本サイトは、裁判所ウェブサイト「裁判例検索」に掲載されている裁判例の書誌情報・判示事項・裁判要旨などを、ブラウザ上で検索・閲覧できるようにした個人運営の無料サービスです。利用に登録や料金は不要です。

2. 収録データと出典

裁判例の原データは裁判所ウェブサイト（courts.go.jp）です。本サイトは、同サイトを収集して公開されている japanese-law-analysis/data_set（CC0）を取り込んで利用しています。判決・決定は著作権法第13条第3号により著作権の目的とならない著作物です。

本サイトに表示される「主文（冒頭抜粋）」は判決文PDFからの機械抽出であり、誤変換や欠落を含むことがあります。「分野」は事件番号の符号などから機械的に推定したものです。「解説」は編集部による要約であり、判決の原文ではありません。

3. 免責事項

本サイトの情報は、裁判例を探す手がかりとして提供するものであり、その正確性・完全性・最新性を保証するものではありません。引用や法的判断に用いる場合は、必ず裁判所ウェブサイトの原文（全文PDF）や判例集で内容を確認してください。

本サイトは法的助言を提供するものではありません。個別の事案については弁護士等の専門家にご相談ください。本サイトの利用により生じたいかなる損害についても、運営者は責任を負いません。

AI要約・質問機能は、利用者自身が設定したAPIキー、または claude.ai 上の閲覧者自身のアカウントで動作します。AIの回答は誤りを含むことがあり、その内容について運営者は責任を負いません。

4. プライバシーポリシー

本サイトは利用者の登録を求めず、検索語や閲覧した判例をサーバーに送信しません。検索・絞り込み・類似判例の計算はすべて利用者のブラウザ内で行われます。

ブックマーク、メモ、検索履歴、表示設定、APIキーは、利用者のブラウザのローカルストレージにのみ保存され、運営者には送信されません。これらはブラウザのサイトデータを削除すると消去されます。

AI機能を利用者自身のAPIキーで使う場合、判例の情報と質問文は利用者のブラウザから直接 Anthropic 社のAPI（api.anthropic.com）に送信されます。送信される内容の取扱いは同社のプライバシーポリシーに従います。

本サイトは GitHub Pages 上で配信されています。配信に伴うアクセスログの取扱いは GitHub 社のプライバシーポリシーに従います。本サイトが独自にアクセス解析を行う場合は、Cookieを使わない方式を採用し、本ページに明記します。

本サイトへの過度なアクセス、サーバーや配信に負荷を与える行為、本サイトの情報を用いて第三者の権利や名誉を侵害する行為を禁止します。
